# ATD Harbor Club — 3D Multiplayer Prototype

## 실행
1. Node.js 18 이상 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 접속

## 멀티플레이
같은 서버의 주소와 포트(3000)에 접속한 플레이어들이 같은 월드에서 보입니다.
외부 친구와 플레이하려면 이 프로젝트를 인터넷에 공개된 Node.js 호스팅에 배포해야 합니다.
현재 프로토타입은 실시간 플레이어 위치와 아이템 획득/선박 적용 상태를 WebSocket으로 동기화합니다.

## 조작
- WASD: 이동
- 마우스: 카메라 회전 (항구 입장 후 마우스 잠금)
- Shift: 달리기
- E: 아이템 줍기 / 선박 근처에서 적용
- G: 내려놓기

## 참고
이것은 새로 만든 3D 웹 프로토타입이며, 사용자가 제공한 원본 사이트의 소스나 에셋을 수정한 것은 아닙니다.
Three.js는 브라우저에서 CDN으로 불러오므로 처음 실행 시 인터넷 연결이 필요합니다.
실서비스 배포 전에는 서버 측 거리 검증, 아이템 소유권/경합 처리, 방 생성, 계정 및 치트 방지 로직을 보강해야 합니다.
